Release: V8 · Facility-name contour labels + seasonal/sub-seasonal facility gradients + muted publication-style visual design

Core platform retained:
- Zambia: all 116 districts

- short-, medium-, sub-seasonal and seasonal forecast workflows

V8 revisions:
- every facility contour/gradient plot prints facility names beside the sampled points in addition to labelled contour values
- facility gradient visualisation is now consistent across short range, medium range, sub-seasonal (weeks 2–6) and seasonal (months 1–7) workflows
- long-range facility gradients use physical ECMWF EC46/SEAS5 temperature and precipitation anomalies already fetched for the active facility screen; no duplicate API request is introduced
- seasonal/sub-seasonal temperature and precipitation anomaly gradients are paired with direct facility bar charts
- contours, markers, bars and model-comparison charts use a calmer muted publication-style palette with increased transparency
- the main analysis tabs use muted filled colours with a restrained active-state highlight rather than bright saturated gradients
- Forecast setup controls use softer translucent fills while retaining larger, readable selected text
- the scientific boundary remains explicit: contour surfaces are IDW visualisations of facility point samples, not native model grids

Scientific boundary:
A facility-specific forecast is a point-specific hazard/exposure signal. A facility contour surface is an IDW visual interpolation of those point samples, not the native model grid. Operational facility risk must not be inferred unless readiness/access data such as staffing, WASH, electricity, cold chain, service availability or access disruption are explicitly integrated.
